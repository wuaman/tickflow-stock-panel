# 财报三问

> A 股入门:看一家公司不用背一堆指标。先会问三个问题,每个问题对应一个指标,你就能对着财务分析页看出点门道。

看一家公司,新手只需要按顺序回答三个问题:

| 问题 | 指标 | 中文名 |
| --- | --- | --- |
| ① 它赚不赚钱? | EPS | 每股收益 |
| ② 赚钱效率高不高? | ROE | 净资产收益率 |
| ③ 生意有没有变大? | 营收增速 | 同比 |

---

## 第一课 · EPS(每股收益)——它赚不赚钱?

**一句话**:净利润 ÷ 总股本 —— 摊到每一股上,公司这一年帮你赚了多少钱。

- **怎么看**:别盯着单年数字,看连续几年的**趋势**。单年 EPS = 1.5 元说明不了什么;连续 0.8 → 1.0 → 1.3 → 1.5 → 1.9 才叫「盈利往上走」。
- **在项目里**:财务分析页的 `eps_basic` 字段。
- **练习**:选 2 家你认识的公司,把近 3 年 EPS 抄下来排一排,看它是往上、往下、还是忽高忽低。

## 第二课 · ROE(净资产收益率)——赚钱效率高不高?

**一句话**:净利润 ÷ 净资产 —— 你投进去的每一块钱,公司帮你赚回了多少。

- **为什么重要**:巴菲特最看重的指标之一,反映一家公司有没有「护城河」——好公司用同样的钱能赚更多。
- **经验值**:长期 ROE 稳定在 **15% 以上** 算优秀,低于 10% 要多留个心眼。这是经验,不是铁律。
- **在项目里**:财务分析页的 `roe` 字段。
- **练习**:找同行业两家公司,比谁的 ROE 更高、更稳定。跨行业比意义不大——银行和白酒不能直接比。

## 第三课 · 营收 + 营收增速——生意有没有变大?

**一句话**:营收 = 公司卖了多少钱的东西或服务;增速 = 今年比去年涨了多少。

- **为什么重要**:利润可以「做」出来——卖资产、砍成本、一次性收益都能让利润变好看。但**营收增长更真实**,它代表生意本身在扩大。营收连续几年不涨的公司,利润再好看也要警惕。
- **在项目里**:财务分析页的 `revenue`(营收)与 `revenue_yoy`(同比增速)字段。
- **练习**:看营收同比,连续 3 年都正增长的公司,才值得花时间继续往下看。

## 第四课 · PE(市盈率)——价格贵不贵?(先知道概念,别深究)

**一句话**:股价 ÷ EPS —— 粗略等于「按现在的盈利,你买这家公司多少年能回本」。

- **怎么用**:PE **不能孤立看**,必须和同行比、和自己的历史比。PE 30 不一定贵,PE 5 不一定便宜。
- **节奏**:等前三个指标都熟了再碰估值。现在只要记住一句话:PE 衡量的是「价格贵不贵」。

## 上手节奏

别一次吃太多,按周推进:

| 周次 | 内容 |
| --- | --- |
| 第 1 周 | 只搞 EPS + ROE,用 3~5 家自选股练 |
| 第 2 周 | 加入营收增速 |
| 第 3 周 | 再碰 PE 和估值 |

## 怎么用这个项目练

1. 在自选股里加 3~5 家你**真正认识**的公司——你天天用它的产品、消费它的服务,这种最好。
2. 同步自选股的财务数据:

   ```bash
   curl -X POST 'http://127.0.0.1:3018/api/financials/sync/all?scope=watchlist'
   ```

3. 财务分析页右上角保持「自选股」,打开一家公司,看它的 `eps_basic` / `roe` / `revenue` 三列。

## 避坑提醒

> 看指标是为了「比较」,不是为了「背数字」。孤立的一个 EPS、一个 ROE 本身什么都说明不了,只有「和去年比、和同行比」才有意义。这也是小白最容易犯的错——记住一堆数字,却不知道怎么判断好坏。
